Skully privacy policy Skully is a private assistant used only by its owner. Nobody else can sign in to it. What it accesses When the owner signs in with Google, Skully can read the owner's Gmail, Calendar, Drive, Contacts and Tasks, send email, and add calendar events and tasks. It sends or adds something only after the owner approves that specific action. How the data is used Google data is used only to answer the owner's own requests. To do that, the relevant text is processed on the owner's home server and by the Anthropic API, which generates the assistant's replies. It is not sold, shared with anyone else, or used for advertising. Storage Skully keeps a sign-in token on the owner's home server so it can reach the account. It does not keep a copy of the owner's mail, files, contacts or calendar. Removing access The owner can remove Skully's access at any time at myaccount.google.com/connections, which makes the stored token useless.
